# 火拼炸弹堂 · 设计文档（v1.0）

面向交付的可玩版本：Godot 4.7 + GDScript，单人/双人同屏，对阵 AI。

## 一句话
俯视角格子炸弹竞技：放炸弹炸砖块、吃道具变强、把对手炸飞出局，三局两胜。

## 参考与差异
玩法骨架取自经典炸弹人 / QQ堂（放弹—走位—炸砖—抢道具—互相击杀）。
本项目为原创实现与原创美术/音频，标题、角色、关卡、代码均自研，不含任何第三方素材。

## 核心规则
- 场地：15 × 11 格，格子 48px，视口 1280 × 720。
- 边界为钢墙，内部偶数坐标固定钢墙（4 个对称柱阵），其余为空地与可破坏木箱。
- 出生点在四角 (1,1) (13,1) (1,9) (13,9)，出生区 2 格内保证无箱子。
- 炸弹：按放弹键在当前格放置，引信 2.4 秒，爆炸沿上下左右各延伸 `火力` 格，遇到钢墙停止；炸到木箱则摧毁并停止；炸到其它炸弹则立即引爆（连锁）。
- 站在爆炸格上的角色立即出局（护盾生效期间免疫一次）。
- 木箱被炸后 38% 概率掉落道具。
- 一局 = 最后存活者胜；同归于尽判平（双方都不得分）。
- 一场 = 三局两胜（先到 2 胜结束）；单局超时 120 秒则按「炸箱数 → 击杀数 → 平局」判定。

## 属性与道具
| 属性 | 初始 | 上限 |
|---|---|---|
| 炸弹数 | 1 | 6 |
| 火力（爆炸半径） | 1 | 6 |
| 移动速度 | 4.2 格/秒 | +4（每级 +0.55） |

道具：炸弹 +1、火力 +1、速度 +1、护盾（5 秒无敌，可挡一次爆炸）。

## 操作
- P1：WASD 移动，空格/J 放弹。
- P2：方向键移动，回车 / 小键盘 0 放弹。
- Esc 暂停，F11 全屏，M 静音。

## 模式
1. 单人闯关：玩家 + 3 个 AI，难度 简单 / 普通 / 困难。
2. 双人同屏：P1 + P2 + 2 个 AI。
3. 双人对战：P1 vs P2（无 AI）。

## AI 设计
- 每 0.45 / 0.28 / 0.16 秒思考一次（对应难度），产出「方向 + 是否放弹」的意图。
- 危险图：由现有炸弹推算每格「多久后会烧到」。
- 决策优先级：逃离危险 → 抢可达道具 → 贴箱放弹（放完有退路才放）→ 逼近对手 / 巡逻。
- 逃生判定：放弹前模拟爆炸范围，BFS 找 1.2 秒内可达的安全格，找不到就不放。
- 难度差异：思考频率、放弹积极性、误判率、对连锁的预判。

## 体验目标
- 输入延迟感低：格子对齐 + 平滑插值，允许「按住方向自动连走」。
- 打击感：屏幕震动、爆炸分帧、砖块碎屑、击杀横幅、连击计数、放大浮现分数。
- 音乐：菜单曲 + 战斗曲（8-bit 合成），音效 12 种。
- 存档：设置（音量/全屏/震屏）、累计战绩（胜场、最高连胜、总局数）。

## 技术
- 全部界面与实体在代码中构建（code-first），仅 `main.tscn` + `main.gd` 为入口。
- 素材由 `tools/gen_art.py`（Pillow 像素画）与 `tools/gen_audio.py`（NumPy 合成）生成，可复现。
- 自测：`-- --selftest` 无头跑固定步长对战并断言核心规则。
